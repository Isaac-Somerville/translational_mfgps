# translational_mfgps
Repository accompanying research article "Multi-Fidelity Gaussian Processes for Translational Modelling of Clinical Outcomes" (https://arxiv.org/abs/2609.05007) containing all MFGP model fitting and results. Code for simulating drug effects on action potential duration for multiple species can be found here: https://github.com/Isaac-Somerville/apd_drug_effects
